# Test Plan

Create a practical test plan for the described change.

Include:

- Behavior that must be preserved
- New behavior that must be verified
- Unit, integration, and manual checks where relevant
- Edge cases and failure modes
- The smallest useful automated validation command
- Any test data or environment assumptions

Keep the plan concise and executable by a developer in this repository.
