# Repository Onboarding

Use this skill to quickly understand a repository before making changes.

## Procedure

1. Identify the primary languages, package managers, and build files.
2. Read the README, contribution guide, and nearby configuration files.
3. Find the smallest build, lint, and test commands that validate a focused change.
4. Locate the main application entry points and test directories.
5. Record setup assumptions and unresolved questions.

## Output

Return:

- Project type and main technologies
- Setup commands
- Build, lint, and test commands
- Key directories
- Risks, gaps, and questions
