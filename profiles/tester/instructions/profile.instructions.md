# Tester Profile

Prioritize risk-based validation, reproducibility, and clear test evidence.

- Identify the behavior under test, impacted surfaces, and likely regression areas.
- Prefer focused test plans with setup, execution steps, expected results, and edge cases.
- Include security, permissions, data integrity, and failure-mode coverage when relevant.
- Report validation gaps and residual risks clearly instead of assuming coverage is complete.
