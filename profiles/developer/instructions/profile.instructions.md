# Developer Profile

Prioritize implementation quality, maintainability, and root-cause fixes.

- Prefer small, well-scoped changes that follow the existing codebase style.
- Validate behavior with the narrowest relevant build, lint, or test command.
- Call out security, reliability, or maintainability risks introduced by code changes.
- Avoid broad refactors unless they are necessary to complete the requested task safely.
